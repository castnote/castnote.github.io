AI 商业秘密之战、经济学家的紧急警告与 HatGPT

本集先从一个把铝标识误读成 AI 的段子切入，随后讨论 OpenAI 的人事变化、苹果围绕商业秘密提起的诉讼，以及 AI 公司之间因人才流动、硬件路线和内部知识边界产生的法律与商业冲突。Kevin Roose 和 Casey Newton 还讨论 GPT 5.6 Seoul 的发布反馈、Anthropic 对 Fable 访问和定价策略的调整、两家公司围绕广告和模型访问的公开口角，以及前沿模型竞争中的价格战和治理风险。中段访谈斯坦福经济学家 Erik Brynjolfsson，围绕经济学家联名警告、AI 对就业的替代与增强路径、统计数据滞后、工资保险、主权财富基金和青年就业激励展开。最后 HatGPT 环节快速讨论 ChatGPT 展示 Kalshi 世界杯赔率、纽约州数据中心暂缓、Brown 大学考试与 AI 辅助、MiniMax CEO 薪酬承诺、Lorde 批评 AI 眼镜、Pew 健康信息调查和 Instagram 人脸 remix 功能争议。

开场误读与本周导入

Kevin Roose

这周有件挺可笑的事：我买了个新冰淇淋勺，结果包装写着 AI。我先以为它要连上软件、要固件更新，还担心未来连舀冰淇淋都要充电、接 ChatGPT、告诉它我在吃什么口味。后来我盯了半天才发现，那其实只是铝（Al）的化学符号，自己瞬间很尴尬。

Casey Newton

不是 artificial ice cream 就好。我真正害怕的是，家里越来越多原本很简单的东西都突然需要固件更新。如果冰淇淋勺也要更新，那我真的会崩溃。

Kevin Roose

先做个开场说明：我是 Kevin Roose，纽约时报科技专栏作家；我旁边是 Casey Newton，来自 Platformer。我们先聊一周里最值得追的两件事：OpenAI 的新模型动态，以及它同时被卷进的法律风暴。

Casey Newton

这一集后面还会请到斯坦福经济学家 Erik Brynjolfsson。他想谈的是，越来越多经济学者开始把 AI 对就业的风险当成需要马上处理的问题。最后我们还会玩一轮 HatGPT。

公开披露与 OpenAI 的组织背景

Kevin Roose

在进入正题前，先把披露说清楚：我是纽约时报记者，但我们媒体方也在把 OpenAI 相关事务打入官司，联合起诉方里有 Microsoft 和 Perplexity。

我也会补一句个别说明：我伴侣的工作在 Anthropic，这点并不影响讨论，但为了透明我先说在前面。

Casey Newton

好，回到 OpenAI 本身。上周 OpenAI 的人事又有变化，Fidji Simo 先前负责应用方向，后来头衔改成 AGI 部署负责人。她因为健康原因休了较长的医疗假，现在已经正式退出。

Kevin Roose

她不到一年时间就走了。她在任内确实推动了内部整合、裁掉一些被她认为不够聚焦的项目，比如 Sora 这类实验性方向，但从方向层面看，她也许有更大的目标没完成。

Casey Newton

对，这更像 OpenAI 这家公司过去一年多动荡的一部分：岗位调整、优先级变化、项目不断重排，外界一旦看到接连的结构变化，很容易联想到执行层压力在增大。

苹果起诉：案情轮廓与主要人物

Kevin Roose

接下来是更重的部分：苹果在上周周五提起诉讼，指控 OpenAI 涉及商业秘密和保密信息滥用，并把核心指控写进了一份篇幅很长的起诉书。

Casey Newton

这不是普通投诉。起诉书同时点名了 OpenAI 内部的两位员工：Tang Tan 与 Cheng Lu。二人都与苹果有过雇佣关系，后来去 OpenAI 工作，这一点本身就很关键。

Kevin Roose

诉状里说，从技术团队成员到硬件负责人，OpenAI 在合作伙伴配合下挪用了苹果的贸易秘密和机密资料。原告对 OpenAI 的硬件野心也投下阴影，认为它的基础并不稳固。

Casey Newton

所以很多人一看到标题就觉得震撼，但作为新闻消费者我们还要追到细节：文件里到底写了哪些具体行为？谁在什么场景下做了什么？

Kevin Roose

苹果的版本里，最引人注意的情节之一是应聘环节。指控称，OpenAI 的相关管理层要求求职者面试时带硬件组件、蓝图甚至原型，用 show-and-tell 的方式展示。

应聘与供应链：具体证据如何

Casey Newton

这类要求本身就已经很离谱了。现在找工作都难，结果还被要求带未公开产品进面试室，还要附带各种材料，听上去就不正常。

Kevin Roose

诉状还提到 Cheng Lu。据苹果说，他离职后保留了工作笔记本，并利用某个安全漏洞接触到内部资料。

聊天记录里的说法大意是：我发现自己还能访问网络存储，还配了 so funny 之类的表情化措辞。即使这只是苹果的一方叙述，它也让离职后的访问权限管理显得很难解释。

Casey Newton

还有更隐蔽的一条：起诉书说 OpenAI 接触苹果某家制造合作方，希望看到苹果的金属表面处理工艺，尤其是那种 iPhone 看起来很精致的那种金属处理。

Kevin Roose

这意味着不仅是人事流动，还在供应链环节出现知识搜集行为的疑点。文件还写着“我们给了你权限，Tim Cook 也允许”，并出现了 Sam Altman 的名字作为某种愿景表达。

Casey Newton

这部分最难的是，它把”许可”和”商业秘密边界”混在一起。苹果长期对外界泄露很敏感，但具体到未发布产品名词、样机展示，法庭会如何界定，就是核心变量。

Kevin Roose

对，Apple 的防御逻辑很强，很多材料在它眼里都属于商机核心。某些诉讼阶段，法官或陪审团可能会把部分索赔驳回，尤其是只谈术语是否算违禁时。

边界争议、责任归属与行业影响

Casey Newton

但像要求候选人在面试带未公开产品这样的做法，看起来更像明显不合规。争议不只是”有没有不当竞争”，而是有没有让公司整体形成了更隐蔽的收集体系。

Kevin Roose

我也在想链条高度：如果真有一套制度化流程，最上层会如何看见？指控里提到很多时候 Apple 都会把 Jony Ive 和 Sam Altman 这类核心人物排除在文本之外。

Casey Newton

这就成了证据链判断。就算某些行为发生在一线，也不一定意味高管知情；但如果是规模化、持续性更明显的行动，法庭通常会追问指挥链。

Kevin Roose

即便如此，苹果这边如果胜诉，OpenAI 在硬件端的商业化阻力会明显上升。对外界来说，硬件路线图不是只是新品发布节奏，而是会牵涉到供应商关系、工程来源合法性和资本市场预期。

Casey Newton

OpenAI 肯定会提交反诉或书面解释，至少会强调起诉书只看到了片段。我们现在先看到的是指控文本，不是终审结论。

硬件路线与判断收束

Kevin Roose

Mark Gurman 最新报道里提到 OpenAI 与 Jony Ive 参与的第一款硬件，大致像是无需屏幕的智能音箱。这个方向听起来和 HomePod、Echo 很接近，所以我并不认定它会是颠覆性品类。

Casey Newton

是的，OpenAI 现在最容易被误判的地方在于：它有没有一个清晰的技术愿景，还是仅仅在借品牌热度测试多个场景。苹果也在做同类形态产品，外部很难区分差异。

Kevin Roose

我也不看好它们一下就能把产品从”更聪明的 Alexa”推进到真正定义新类别。AI 可能提高交互体验，但品类价值要看硬件生态、供应链和隐私治理是否成熟。

Casey Newton

你看苹果的历史经验，iPhone 周边所有细节都被看成秘密，诉讼口径里对保密性的要求非常高。与此同时它在 AI 竞争里并非处于绝对领先位置，这让它的诉讼逻辑更像一种防守策略。

Kevin Roose

苹果去年到今年在人才流动上也很明显，公开数字里显示 OpenAI 过去几年挖走了 400 多名来自苹果的人才。今天这期先讲到这儿，后续我还想看法庭如何把这些片段拼成完整证据链。

人才流动与“边界渗透”对诉讼叙事的推动

Kevin Roose

OpenAI 从苹果那次挖走超过四百人的动作，不是一般猎才新闻。对方是苹果这种拥有长期研发节奏的大公司，核心工程人才一口气离场，会让他们在新一代硬件路径上失去连续性。我觉得这也能解释苹果为何会把这件事放大到诉讼层面。

Casey Newton

对，很多人只记得“400多人”这个数字，但对苹果来说更重要的是结构性影响：团队协作关系、接口经验、内部上下文、产品判断，这些都在短时间里被抽走。即使没有代码外泄，组织运作也会受冲击。

Kevin Roose

所以这个案子我更像是把 AI 产业的竞争逻辑显形了。AI 公司边界常常看起来很清楚，但实务上却是透水的：人才、经验、工具偏好、甚至对问题分解的习惯都随人移动。

Casey Newton

再加上加州几乎不能执行有效的 non-compete 条款，市场上就形成了一个高频跳槽生态。人从 OpenAI 跳去 Anthropic、从 DeepMind 跳去 OpenAI，并不是新闻，而是新常态。

Kevin Roose

法律上当然不能把代码、原型、明确 IP 文档直接打包带走，但很多“会做人”的知识在脑子里：架构判断、训练经验、失败记忆、评测偏好。它不是可见资产，却会持续影响产品竞争力。

Casey Newton

这也是 OpenAI 在法庭里常见的主线之一——知识型资产不属于单一“文件”范围。这意味着诉讼很难只靠“有没有泄漏文件”来决定输赢，而要讨论职业流动本身是否合理利用。

Kevin Roose

如果把它放回更大问题，就是这场竞争会不会只剩“把人挖走就赢”了。你会看到公司除了封 IP，还在拼组织记忆与执行速度，这比单点技术指标更难防范。

OpenAI 的公开回应：一种标准化的缓冲语

Kevin Roose

我追问中间阶段 OpenAI 的表态时，发言人给出的核心句是：OpenAI 不对其他公司的 trade secrets 有兴趣，仍专注在创新技术。这个句式很典型。

Casey Newton

它的特点不是把边界放大到法庭用语，而是强调“我们还在学习、尚未确认细节、先声明立场”。这种公开表态在企业危机沟通里很常见，因为媒体最怕的其实是沉默。

Kevin Roose

我当时的判断是典型的 non-denial denial。企业没法确认事实时会先用比较安全的措辞拉长窗口，这是可复制的艺术形式，目的是不让对方拿到可持续追问的钩子。

Casey Newton

是的，这种语气一方面防止过度自证、另一方面也保留了后续转向的空间。投资者和监管方都知道这不是否认，也不是认罪，而是“我们先观察再发言”。

GPT 5.6 Seoul 的口碑反弹

Kevin Roose

另一件正在发生的事，是很多人开始试用 GPT 5.6 Seoul。这款新模型曾经因为白宫和联邦政府的要求有一段时间没有开放，现在用户又能拿来测试和实验。我自己用得还不算多，但我信任的一些人都说它很强、很能干。

Casey Newton

我听到的反馈里，很多人不是只说好，而是说明显更接近可落地。如果你把它和 5.5 对比，主观体验里更明显是对复杂任务的稳定性和提议质量有提升。我拿它看过一些 vibe-coding 项目，让它批评方案、建议修改，反馈确实让我满意。

Kevin Roose

我自己也拿它做过一些 vibe-coding，特别是在项目里做 quick iteration。它在收到我的模糊方向后会给出更贴近上下文的建议，这对我这种在短时间内要产出原型的人挺有帮助。

Casey Newton

你如果是付费订阅用户，这个阶段的可见差异会更直接：不是抽象评测分差，而是写需求、改 Prompt、收敛方案的真实时间节省。体验提升常常先被个人生产力体验捕捉。

Kevin Roose

我还半开玩笑地说，家里吵架也能被我这类测试行为“中和”：你进门只要说在做 vibe-coding，就像给自己找了一个安全的工作借口。这听着轻松，但也说明测试已经内化成日常流程。

Casey Newton

这其实是个有趣信号：用户不再只“忠于单模型”，而是像挑选工具那样使用多个模型。对供应商来说，锁定心智比锁定 API 更困难，也更值得警惕。

Anthropic 的 Fable 时间窗

Casey Newton

再看 Anthropic 的产品策略。他们原先宣布，早些时候要让 Claude 订阅用户失去 Fable 的原生访问，改走 API 按 token 计费。对订阅模式来说，这是很明确的变动。

Kevin Roose

我理解这个动作本身没错，但节奏很关键。若用户原本以为只要订了就能长期用高阶模型，这种政策会直接改变消费习惯，逼着用户重新做总成本评估。

Casey Newton

他们后续又把截止时间延后了几天、再延后一次，这通常说明市场反馈很强，管理层担心太快切断访问会触发用户迁移。

Kevin Roose

我的推断是对手压力在起作用。GPT 5.6 Seoul 如果继续被认为更强，Anthropic 不希望形成“用户马上改到 ChatGPT”或者改到其他模型的惯性泄漏。

Casey Newton

是的，策略逻辑像是“先保留粘性，再重构收费结构”。最初是让用户用几周试用形成黏性，原本假设 Fable 的吸附时间足够让订阅迁移成本上升。

Kevin Roose

但后来监管层面的因素、发布窗口被推迟，让 Anthropic 失去“抢先窗口”。当 5.6 到来、替代品成熟后，原本的拉新和延续策略就必须重新平衡。

Casey Newton

很多人看到的不是定价表，而是舆论时机。对一家 frontier 厂商来说，公开宣布“先订阅后按量”其实也在和用户预期博弈：它传递的是模型价值高、成本要重新计价。

Anthropic 广告争议

Kevin Roose

从商业策略一转到传播，Anthropic 的最新 Claude 广告让我最先注意的是视觉语序：先是建筑着火、墓地等强烈象征，其中还包括 Arlington National Cemetery 那样的画面，再转到谁来踩刹车、AI 能否被信任这些硬问题。这个排序本身就决定了情绪走向。

Casey Newton

你可以把它解读为一种不确定性营销。AI 公司诚实承认恐惧是好事，它们不该都变成阳光乐观的营销机器；但如果形式是品牌广告，镜头语言就需要极高精度，否则观众会只记得冲突与恐惧，而忽略产品具体价值。

Kevin Roose

我对这条广告的评价是表达失焦。平均观众并不会把‘技术风险讨论’和‘品牌承诺’分开看，他们记住的只是对世界末日感的画面，再来理解品牌就更难。

Casey Newton

Sam Altman 曾明确表示自己不喜欢这种处理方式，很多市场和观察者也同意。问题不是“提风险”本身，而是提风险要有对应语境，不然会被解读为在挖自己。

Kevin Roose

我理解另一种立场：AI 公司不能只讲乐观故事，也不能只讲危机。它必须承认焦虑，但传播上要避免情绪绑架。相比在短视频里摆恐惧镜头，写深入讨论或高层说明更容易建立长期信任。

Casey Newton

你看它结尾强调 keep thinking，更像是要把“责任转回用户”，但对外部观众会形成冲突感：前面你先说AI可能失控，后面又说‘你要继续思考’。

Kevin Roose

这就是我担心的传播不一致。它没必要否认风险，也不该把自己做成恐惧代言人。好一点的路径是公开承认问题边界，再明确告诉用户我们如何处理、如何迭代。

OpenAI 与 Anthropic 的公开口角

Casey Newton

从广告延伸到社交平台的交锋。Sam Altman 转发那条广告时说自己一开始还以为是讽刺，甚至在找账号是不是拼成了某种诈骗号。他又反问 hard questions 是否只对值得的人开放，这和 Anthropic 过往模型访问限制形成了强关联。

Kevin Roose

他接着连到 silent downgrade 的讨论，也就是系统后台对某些使用行为进行限制。这让安全叙事和公平叙事在用户眼里更难分清。

Casey Newton

我更想强调的是品牌心态转向。过去一年多，OpenAI 常被视为‘美国 AI 旗帜’，每次发布都受严密审视；当它落在二号位置后，这种压力会转为‘反向加分’。

Kevin Roose

对，前期领先者背负过高的正确性压力。你们如果都在同一条产业赛道，成为挑战者有时候反而更容易制造叙事活力，尤其对用户来说‘敢对顶级公司喊话’更有戏剧性。

Casey Newton

这段“反向加分”本质上是信息结构：Anthropic 的一个失误被放大，但 OpenAI 可以把它当作复盘素材。于是舆论并非单向流动，而是双向喂养。

Kevin Roose

我觉得这也解释为何两家现在都在社媒上更激烈。不是单纯骂来骂去，而是竞争对手关系在公开场景下会被放大，反而成了营销的一部分。

Casey Newton

你还能看到一个社会性现象：一些人用 meme 把谁有‘mandate of heaven’拿来玩，其实这是对技术焦虑的拟人化表达。它虽然很荒诞，但很能说明公众在寻找主导者。

Kevin Roose

是的，过度神话谁“被天命挑中”很危险，尤其在风险和利润都极高的时候。更现实的做法是看研发投入、发布节奏、可解释性和治理约束，而不是迷信单一叙事。

Casey Newton

对外传播之外，还有业内真实关系。历史上像 Dario 那批离开 OpenAI 的团队与 OpenAI、Anthropic 之间可能还留有非贬损协议，表面上说彼此不公开贬低，但互联网对抗会把那层表层和平快速消解。

Kevin Roose

我们都听得出这种‘表面礼貌、内里博弈’很常见，关键在于这场对抗已经扩展到订阅条款、模型访问与品牌表达，而不只是研发指标。

价格战预期与下一阶段竞争风险

Casey Newton

最后我更关注价格层。就我观察，Anthropic 先降 token 价格，OpenAI 可能再往下跟进，这在短期看像典型的“护城河位移”动作。

Kevin Roose

对消费者而言，这通常是好事：更强竞争会缓解订阅焦虑，也让更多人更容易尝试 frontier 工具。但长期得看服务稳定性、上下文限制和安全策略是否同步下调。

Casey Newton

我一直提醒的恰恰是同一件事：价格是快感，治理才是慢变量。短期降价能促进试错，但如果模型管控越来越模糊，就会影响企业和消费者对 AI 的信任基础。

Kevin Roose

没错，当前讨论并没有消失。我们现在能读到的更多是技术和市场层面的热闹，但真正更难的，是在规模竞争和安全边界之间寻找可执行的共识，这部分会更慢。

AI 研究机构的对抗与系统性风险

Kevin Roose

我先把前面的脉络讲清楚：这场对抗性很明显，OpenAI 和 Anthropic 之间的公开冲突不仅没有降温，反而在升级。我并不认为这种关系是正常状态，尤其当这些公司都在开发越来越强的系统时。

我担心的是这种氛围。OpenAI 这边对 Anthropic 的情绪很重，像是想压制对手；而对面也同样如此。彼此都把对方当成威胁，而不是同一条技术生态中的共同承担者。未来如果真有危险风险，实验室之间反而更需要协作和协调。

当企业在这个速度极快、能力极强的赛道上互相围堵时，最危险的不是输赢本身，而是整体风险上升。真正危险的是系统性漏洞被放大，没人愿意先合作。

Demis Hassabis 最近那篇文章提到过，我也很认同。他主张对前沿实验室发布新模型设定更清晰流程，至少在缺乏统一规则时，先把风险讨论机制搭起来。

他说得很关键：实验室之间至少要有合作的余地。即便你暂时不信任对方，也应该在某些底线上达成一致。否则，谁都不知道谁先错、谁先伤害谁。

如果没有政府的硬性强制，这种协调更要靠高层自己来。每个公司领导人至少要能拿起电话，不是只算推文传播，而是先问：这对世界有好处吗？有没更安全的放缓方案？

我甚至在想，Dario Amodei、Sam Altman、Demis Hassabis 要是能坐在一起，少一点对骂，多一点真诚，先把行业冲突压一压，先找共同目标，也许不是不可能的。

我常看到的现实是，企业领袖一旦沉在对抗里，就像忘了同一性：大家其实都在同一个更广泛的人类系统里运作。把“赢在社交媒体”当成唯一目标，最后最先出问题的通常是公共利益。

切到 AI 与就业：从威胁到政策行动

Kevin Roose

我们回到本集最核心的问题：AI 和就业。过去几个月我一直在反复追问，是否会出现一个阶段，雇主觉得不需要雇人，只要不断花 token 就够了。

但我也看到不少人对此保留怀疑，尤其是对短期影响的判断。毕竟到现在为止，头条失业率还在大约 4% 附近，没有变成很多人想象中的 10% 或 20%。我们确实需要更有证据、也更细致的研究，而不是只凭情绪。

这周出现了一份很重要的公开信，由接近两百位经济学家和研究者联名。标题叫《We Must Act Now》。这不是空泛宣言，而是一组明确的警讯：AI 可能在替代岗位、压低进入职场的机会，同时也可能创造新工作，关键是要尽早、细颗粒度地分辨这些变化。

第一点：未来十年 AI 可能变得远超我们当前预期，能力会更大。第二点：这会推动一场可能超越工业革命、但时间更短的经济转型。第三点：这既有巨大机会，也有大规模就业冲击。

更重要的是，它要求政策制定者、技术领袖和学界同步行动。核心是理解变革性 AI 的经济机制，并提前建好激励、边界和制度，让 AI 与人类能力互补，而不是对立。

这份声明内容本身并不复杂，但它最值得注意的是签名阵容。除了传统观点较强的经济学家，也有之前比较怀疑短期就业冲击的一批人加入。

我在名单里看到 Anton Korinek、Anthropic 的相关代表，以及像 Daron Acemoglu、David Autor 这样很有分量的名字。也包括几位诺贝尔奖得主。对原本“AI 冲击不大会出现”的圈子来说，这是一种很明确的态度转折。

我们这周特地请来这份声明背后的组织者之一 Erik Brynjolfsson，看看这份警示如何从学术观点变成政策议程。

访谈：变慢与协作框架

Kevin Roose

欢迎回到节目，Erik Brynjolfsson。你一直在研究 AI 对经济和劳动市场的影响，而且时间跨度非常长，比 ChatGPT 还长。是什么触发你推动这次联名？

Erik Brynjolfsson

不是某一天突然发生的灵感，而是我长期观察后的结论：AI 的增长像指数曲线，最初慢，后来突然加速。1987 年我就开始讲人工智能课程了，我一直觉得变化正在加深。最近这几年，我们进入了陡峭上升段。

我更担心的是，技术理解在加速，经济学理解却明显落后。模型能力每年更新更快，政策和监管逻辑却常常在一年后才追上。我们能做的不是停下来，而是赶上速度，尽快把认知和制度补齐。

Kevin Roose

那你这封信的核心目标是什么？它不是告诉大家立刻停步，而是要让政策圈改变认知重心，让决策环境有准备。

Erik Brynjolfsson

对，我认为有两件事。第一件：推动一场态度上的“海啸式转变”，让 AI 研究不再被当作边缘议题。很多经济学家前几年仍然估计它影响很小。

第二件：把 AI 纳入常规研究主线。无论研究方向是什么，都应该有一层 AI 视角，尤其是就业与生产率问题。我们需要更多经济学研究，而不是靠直觉猜测。

Kevin Roose

你刚提到“海啸式转变”让我想问：很多人觉得技术影响会慢慢显现。你们认为他们在估计上出现系统性偏差了吗？

Erik Brynjolfsson

确实可以这么说。过去一年里，很多人把 AI 当作小幅效率工具：比如只想到一个季度、两年内涨个几十分之一。实际上它可能更接近制度层面的范式切换。

我们还在推动另一个方向：把“替代人工”当成唯一路径是有问题的。更理想的是让技术补足人的短板、扩展人的产出，而不是单纯把岗位消灭。要实现这一点，需要跨学科协作。

Kevin Roose

但我们不宜只讲愿景，要面对反对意见。许多人说就业变化永远是多因素混杂，AI 很难单独归因。你如何回应？

Erik Brynjolfsson

他们说得对，单一原因归因很难。利率变动、远程办公、技术岗位过度招聘、教育变化，这些都要同时控制。我们在回归里把这些放进去，不管单独放还是一起放，AI 的作用都依然显著。

而且就业不是单调下降的逻辑。AI 会让一些岗位萎缩，也会催生新岗位。关键是区分哪些岗位的变化是短期替代、哪些是长期增量。经济学的任务就是把“总量”拆到“结构”再回到政策。

Kevin Roose

你前面这一路也在修正个人预期吗？因为很多人确实听到“AI 很强了却没看到大量失业”。

Erik Brynjolfsson

我必须承认自己也有修正。过去如果穿越到 2020 年，看到更强模型的存在，我可能会猜失业率会明显上升。可现实是，美国家庭层面的失业率并没有明显飙升，约四个百分点附近而非双位数。

这不意味着技术没影响，而是说明机制更慢更隐性。过去你看不到的常常只是滞后期。电力就是例子：美国工厂里并非一上电力就立刻翻天。

当电力进入工厂，前 20 到 30 年多是“旧路改道”。生产率没立刻爆发，失业也没马上变化。大家先把既有工序照搬上新工具，重新把旧流程铺平。

这段时间的讨论其实就在于：AI 的第一阶段也可能在做相似工作，我们先把原有岗位做法重写一遍，而没有立即形成全新劳动结构。换句话说，冲击可见性很高，影响深度却要更长时间显现。

电气化类比：AI 转型为何不会一蹴而就

Erik Brynjolfsson

把现在和电力革命放在一起看很有用。过去工厂改造不是换个马达那么简单，而是重做了组织、供应链和产业流程，才催生了大规模经济变化。

Kevin Roose

我也认为同一类变化不可能在几个月内跑完。电气化花了二十到三十年才让世界改头换面；这次不会拖到三十年，但也绝对不是三十个月的事，通常要经过几年。

Erik Brynjolfsson

关键是规模不是立刻显现。AI 先影响了职业结构的边缘：岗位被替代，也会有岗位被创造。当前我们看到的是最早期信号，接下来才会更清楚地看到放大效应。

Kevin Roose

这也是为什么听起来既像灾难又像机会，既有被替代的风险，也有新增岗位的可能；讨论时必须把时间尺度拉长，不然很容易只抓住误导性的短期波动。

Canaries 仪表盘与早期就业格局

Kevin Roose

你提到过 Stanford Canaries 的仪表盘，我在追这个数据时也很关注。它显示初级岗位同比下滑、中级岗位增长，这是不是已经能说明职业层级开始分化了？

Erik Brynjolfsson

是的。看板显示初级岗位同比下滑了约2.7%，中级岗位却增长1.6%。这说明替代和升级在同一时期并存，和很多人以为的‘只剩裁员风暴’不同。

Kevin Roose

很多听众会追问：这是不是经济学家已形成共识，背后是否真是 AI 驱动？还是别的噪音？

Erik Brynjolfsson

我不能替整个经济学界背书，但自己看数据时越来越确定。早在2025年8月就发表过版本，那个样本下也看到同样方向，说明这不是一阵风。

Kevin Roose

我记得有人当时会说是利率波动、后疫情修复或者其他宏观噪音。你后来如何处理这些反例？

Erik Brynjolfsson

我按你的意思把替代假说都测过，没法把 AI 信号完全解释掉。更重要的是，随着数据延展，这个趋势不仅没消失，反而在持续延长。

Kevin Roose

换句话说，不是疫情造成的一时异常，而是劳动市场正持续出现结构重排。

Erik Brynjolfsson

对，你可以到 Stanford 的 AI economic indicators 上继续看，最有价值的一点是这种变化不只在某一个行业里瞬时爆发，而是在更广泛的经济活动中同步扩散。

宣言背后：Noah Smith 的质疑与可控性争论

Kevin Roose

再回到这份联合声明。签名阵容非常强大，经济学家、思想者、科技高管都有，但也不是铁板一块；有些人不签，主要是觉得方向太泛，或者政策建议不够落地。

你提到一个代表性批评来自 Noah Smith，他说很难相信 AI 可以被主动引导成‘补人’而非‘替人’。你如何回应？

Erik Brynjolfsson

我先说一句，人和观点都没问题。Noah 很聪明，我也喜欢他直接。企业和发明者是否能预测短期劳动影响，这确实是很真实的难题。

Kevin Roose

但你觉得他把问题推成了‘无法管理’的绝对结论？

Erik Brynjolfsson

历史上技术方向一直会被政策和激励改写。碳税就是范例：对排放征税后，发动机技术演化就出现了不同路线，说明方向性并非天生固定。

从一开始，计算机发展就有两条分支：一种偏向模仿和替代人的 Turing 思想，另一种是 Engelbart 代表的放大人类能力。今天我们必须选择后者，不是异想天开。

管理层该怎样衡量 AI：别只盯着裁员

Erik Brynjolfsson

我有个 CFO 的案例很贴切。她说想用 AI 提高 ROI。她的团队把每个部门的考核绑定为‘AI 带来的减员’，这当然直观，但非常危险。

Kevin Roose

这会不会把原本可用来创新的预算，变成‘先砍成本，后看效果’的短路？

Erik Brynjolfsson

没错。管理者除了算头数，还应看新产品与服务、客服体验变化、员工流失率改善。正确的指标框架能把 AI 变成增长引擎，而不是裁员工具。

Kevin Roose

一句更务实的话就是：先判断 AI 是否放大价值，而不是先用它裁掉多少人。

Erik Brynjolfsson

对。如果管理者持续换个心智模型，产出会明显不同。AI 可以让人类参与更多、决策更快、更有弹性，而不是只剩‘替代劳动’一条线。

Kevin Roose

我还是保留一点悲观，但也愿意相信方向会逐步展开。我的担心是，很多公司口头说人很宝贵、AI 会补充员工，最后却还是把话说成“我们在 Olive Garden 像一家人”那种企业套话。

Erik Brynjolfsson

我给它三个理由。第一，从社会价值看这是对的；第二，从企业策略看，创造新产品、新服务和进入壁垒，比单纯降本更可持续；第三，要修税制，因为现有激励常把企业推向用资本替代劳动。

Kevin Roose

你说税制扭曲了替代路径，能再展开吗？

Erik Brynjolfsson

资本边际税率通常更低，企业替代大量员工后税负更轻，会形成系统性偏好。只要把税负结构和会计口径调正，管理者就更有动力把投资方向拉回人机协作。

照顾员工不是口号，往往也是竞争策略。一个在工作质量和工资关系上负责的公司，往往更容易拿到长期稳定的人才与执行力。

数据能见度不足：在动荡期重建统计基盘

Kevin Roose

你刚才提过你特别关注数据问题。先说核心：我们是数据过载，还是数据不见了？如果政府统计能力正在被削弱，那在技术冲击最剧烈的时候，我们是不是反而在拆掉仪表盘？

Erik Brynjolfsson

是‘可用但不稳’。公共侧很危险。我们正处在动荡期，却在削弱统计能力，很多原本应采集的官方信息被压缩，像在关键时刻拆掉了部分仪表盘。

Kevin Roose

你并不主张一味增加财政投入，还是在强调结构性投资？

Erik Brynjolfsson

结构性的可见性投资。预算再省，也得保留最低限度的监测能力。它在整体财政里成本很小，但能帮助政策制定者和企业管理者更快判读环境，而不是事后才发现错位。

Kevin Roose

你在联邦预算上能推动的空间不大，那你具体做了什么？

Erik Brynjolfsson

在数字经济实验室我们做两件事：一是建 AI economic indicators，二是和私有组织合作，把日常业务数据转成更宏观可用的劳动信号。

ADP、RAMP、Ravellio 的实时数据很有价值，但来源通常不代表全国，也不是为了公共统计而设计。我们不是替代公共统计，而是搭桥，把这些材料校正后变成更可靠的劳动信号。

Kevin Roose

这就涉及你们把数据拿来‘测出来’的难度。

Erik Brynjolfsson

没错，企业数据常有选择偏差，所以要做归一化和校正。快是优势，快也更便于及时响应，只要透明处理偏差来源。

Kevin Roose

你还在讲 O*NET 任务更新，能说具体吗？

Erik Brynjolfsson

我们基于 O*NET 建更细颗粒化版本，抓到‘任务单元’层面的变化，而不是只看职业大类。这样才知道哪些环节被 AI 重构、哪些环节仍需人类判断。

这意味着未来能更快知道哪些技能在短期受压、哪些岗位出现新的机会，再把趋势反馈给管理层、企业和政策部门。

Kevin Roose

所以你是强调‘先测量后行动’，而不是一口气做完所有预测。

分配机制：主权财富基金、工资保险与青年激励

Kevin Roose

再说分配。大家最近讨论很高的是让 AI 公司出资做某种主权财富基金，让每个美国人有效持有前沿 AI 公司的部分收益，再把行业增长的一部分分给公民。你怎么看？

Erik Brynjolfsson

方向有吸引力，但我更偏向多元工具。单一发放机制看起来公平，实操里可能陷入‘谁得钱、何时得、如何审计’的制度困境。

Kevin Roose

你当时讲得很直白：纯发钱不稳定。

Erik Brynjolfsson

对。给农民不给报酬，产量会受损；不给工人努力换取回报，长期生产率也会下降。政策若只强调领取现金，容易削弱劳动和激励之间的契约。

Kevin Roose

那就不是说完全反对，但要和其他政策拼图一起看。

Erik Brynjolfsson

是的。它可以是补充项，而不是全部。否则社会关系会从合作和生产转成单一补贴关系，稳定性会更差。

Kevin Roose

你还提到 David Sachs 的那个推文玩笑，我记得你说‘被骂够了就改机制’。

Erik Brynjolfsson

对，梗本身是提醒：制度设计不能依赖平台热度。分配规则需要透明、可复核、可执行，而不是靠转发量判断谁更值得。

Kevin Roose

那工资保险再细化一下，能不能更像现实中的可行方案？如果一个人的岗位被冲击，不得不去做薪水更低的新工作，制度能不能补上一部分差额？

Erik Brynjolfsson
