《Hard Fork Live》第一部分：Satya Nadella 与 Cindy Cohn

本期汇聚了 Hard Fork Live 的三段核心对谈：先是微软 CEO Satya Nadella 回应了当前 AI 竞争中的平台化转向，解释了 Project Solara、AI 代理（agent）硬件、Xbox 调整与就业重构，强调前沿能力应由生态共享而非单一模型垄断。随后由 Node 的 Phil Moen 讲述 Beeple 机器人狗项目在公众面前的数字艺术实验与技术想象边界。最后，前 EFF 执行总监 Cindy Cohn 讨论了加密、隐私、移民与监督法治理、平台商业模式与言论权，强调在被动“隐私无望”的氛围中仍需推动可追责的制度与退出权。

开场与节目说明

Kevin Roose

欢迎来到本期 Hard Fork。今天先放上 Hard Fork Live 的片段：先是 Satya Nadella、接着是艺术家和机器人狗负责人 Phil Moen，最后是前 Electronic Frontier Foundation 主任 Cindy Cohn 的对谈。

Casey Newton

今晚的现场氛围很热闹，票量不多也非常珍贵，安全检查和进场都很顺畅，我们很高兴能和大家见面。

先提醒大家，这次节目会有少量主持人上下场差异：比如不能快放、也不能跳过广告，后续会更接近真实直播。

Kevin Roose

披露下关系：我在《纽约时报》工作；我们这次聊到的公司里有 OpenAI、微软、Perplexity，而我伴侣在 Anthropic。

Casey Newton

这也是为什么很多科技新闻很快会发生变化，今天我们会把重点放在微软的 AI 生态、行业就业、以及隐私权与监管议题。

Satya Nadella 专访：AI 不是一家公司一模型

Kevin Roose

Satya，这里有个坦白：自 2023 年我体验过一次微软 AI 后就没再经常用，后来又被打断不少。你先说说这几年微软 AI 到底发生了什么变化。

Satya Nadella

我理解 AI 不再是单一产品，而是整个人类活动都在被 AI 驱动的生态。问题不在于‘我们有一个模型’，而在于能否让更多企业、更多国家都具备在前沿上生产的能力。微软是平台公司，这也是我们要做的事。

Kevin Roose

你把 Build 大会讲成了平台优先，这和早期的做法差别很大。能展开一下 Project Solara 吗？

Satya Nadella

Project Solara 强调的是 agent-first 硬件，也就是不是只依赖手机界面，而是让终端持续运行代理。我们把处理能力带到更接近你日常场景的设备上。

Kevin Roose

你提到 Windows 本地运行万亿参数模型。这个‘无限制智能’听起来是把智能从云再带回设备端。

Satya Nadella

对。我们希望有一个能在本地持续跑的模型和代理，不用每一个请求都回到云。比如护士在医院走动时，设备能抓取语音并快速转成指令，像真正的工作助手。

Casey Newton

那手机在这套架构里是辅助角色而不是核心了。

Satya Nadella

是的，手机仍然重要，但我们更关注的是无处不在的智能感知层。你可以把它理解为与模型协同的“环境式计算”。

Kevin Roose

再问 Xbox。微软刚刚宣布可能重置，芯片和内存涨价是否成为主因？你怎么看这个代价转嫁？

Satya Nadella

Xbox 已有 25 年历史。问题是如何在硬件和内容之间找到可持续商业平衡。过去很多娱乐体验我们是在补贴，未来要更可持续，但不是牺牲体验，而是重新定价。

Kevin Roose

你提到 100 天计划和 Asha 的调整。价格会不会因此上升？

Satya Nadella

先说芯片供应链和内存压力，很多产品链条都在上行。Xbox 只是其中一例。长期还是要把硬件、游戏发布和订阅等模型做得更一致。

Kevin Roose

很多听众会问 2023 年那周你们为 OpenAI 的风波应对得怎样？

Satya Nadella

那周非常紧张，我们临时搭建了专门组织并接纳大量人才。后来 OpenAI 重组回来了，我们非常庆幸自己没有失去那条线。

Casey Newton

你还保留了当初对 OpenAI 的那份冒险性判断。

Satya Nadella

是的。早期大家都以为很冒险，但对方向没有疑问。现在我们与 OpenAI 的关系更成熟了：既是合作伙伴、也是各自走向的灵活关系。

Kevin Roose

你刚发布的 MAI 模型，能否讲讲你们这边的路线图？

Satya Nadella

MAI 的目标是把智能能力规模化：把模型能力、硬件和数据连接起来，既服务外部合作，也能被微软内生重用。今天的关键不是‘做一个更大模型’，而是给产业提供可持续的基础能力。

Kevin Roose

那么为什么微软会把重点放在‘分发给每家公司一套前沿起点’，而不是只造一个超级模型？

Satya Nadella

因为前沿已不只是模型本身。经济增长要想真正上扬，前沿必须像电力一样普及。企业需要可复用、可替换、可本地化的底座。

Casey Newton

你也多次强调‘token 为基础设施’，那对软件开发和岗位有什么含义？

Satya Nadella

我把它叫作 cognitive coverage。开发者不再只是写更多代码，而是要理解大量由代理产出的方案、验证假设、管理流程。工作本质仍在，但技能定义变了。

Kevin Roose

那就业会不会大规模萎缩？你如何看待这种恐慌和乐观看法的拉锯？

Satya Nadella

我不认同‘二三十年前就知道就业会消失’这种表述。像打印机取代手写一样，工作会重构。技能不是消失，而是转向更高一层的人机协作与监督。

微软要帮助更多人找到不易被自动化替代的任务。比如软件开发者需要更强的判断、问题定义和验证能力，这些仍高度依赖人的“不可训练能力”。

Kevin Roose

有人提议让国家参与 AI 企业股权，像主权基金。你怎么看？

Satya Nadella

我不反对创新框架，像主权财富基金在其他国家也有实践。前提是它不扼杀竞争。AI 的分红要更广泛共享，这个目标值得讨论。

Kevin Roose

你曾提过 10% GDP 增长与 token 成本匹配。现在看来还远吗？

Satya Nadella

10% 不是一个拍脑袋口号。要让效率提升持续到宏观层面，代价和价值必须匹配，否则只是 token 倍增，不是生产力跃迁。

我们要把‘只追逐模型调用量’和‘可支付、可复制、可落地’区分开。短期疯狂试探不能等于长期增长。

Kevin Roose

你刚才提到“不可验证的人力资本”。如果未来每个环节都可由代理封闭闭环，是否会发生根本逆转？

Satya Nadella

在知识工作里并不是每一步都能自动验证。会议里的人际判断、语境理解、价值取舍，经常是非形式化的。AI 会放大能力，但不会替代这类人类资本。

Kevin Roose

你认为这是你对本轮采访最想留给听众的底层结论？

Satya Nadella

AI 像电力一样：你看得到的变化是工具界面，真正变化是社会组织能力。它不是终点，而是新的技术代际起点。

转场：科技艺术与公共空间里的好奇

Kevin Roose

今天对话到这里我们先休息一下，接下来会聊一段非常有意思但更轻一些的内容。

Phil Moen：机器人狗与艺术展项目

Kevin Roose

我想先补一句：这场特别是为了 2026 年的 Hard Fork Live。现在请出场 Phil Moen，Node 的执行董事，也是机器人狗项目的现场负责人。

Casey Newton

这批狗模型的外观看起来和普通玩具不太一样。你先给听众简单讲讲它是谁、有什么关系。

Phil Moen

它们是 Beeple 的新作，六只狗，来自数字艺术实验，脸上有 Mark Zuckerberg、Elon Musk、Jeff Bezos，以及 Pablo Picasso、Andy Warhol、Mike。

Kevin Roose

你们一开始为什么要把艺术家和科技高管都放进同一套角色里？

Phil Moen

因为大众对世界的想象越来越通过数字媒体形成，半部作品的含义来自你在媒体里见到的人物。我们希望把“科技精英神话”与“艺术语境”放在同一头上。

Kevin Roose

当你们把它们带到旧金山街头时，反应有多炸裂？

Phil Moen

基本是‘全场手机起立’。观众先反应是拍照、拍视频，再开始围观讨论，孩子尤其兴奋。很多人说这像在看某个“未来版本的狗”。

Casey Newton

你刚才说它会持续拍照，甚至有‘poop mode’？

Phil Moen

是的。它们会持续采集环境影像，不同面具会产出不同风格画面。我们在现场有专门的人专门处理这些素材。

Kevin Roose

这听起来有点喜剧也有点不安。你自己也觉得这个技术叙事会不会在边界上出问题？

Phil Moen

我们不想把它做成武器展示，主要是测试公众对拟人技术的本能反应。作品本身有点荒诞，但也在讨论‘真实感知’与‘算法视觉’之间的距离。

Casey Newton

Node 还做了更长期的保存和展陈考量？

Phil Moen

很多数字艺术作品会快进快出，硬件一过期就没了。Node 想解决的是保存问题：艺术不是短周期的软件玩具，而是要为后人保存。

Kevin Roose

今天这段很有意思，等下我们回到真正的硬核题目，今晚最后的访谈会非常关键。

Cindy Cohn 对谈：隐私、加密与平台权力

Kevin Roose

欢迎大家，下一位是前 EFF 主席 Cindy Cohn。我们想先问你，为什么在你看来媒体独立性比以往更重要？

Cindy Cohn

在新闻生态中，压力并不是新的，但确实更集中。独立媒体需要持续把事实和上下文放给受众，即便结果会对报道者不利。

Casey Newton

你最近长期捍卫 Signal 和 HTTPS，能否解释 EFF 在加密上的核心立场？

Cindy Cohn

我们赢了一些关键战斗，让端到端加密、设备丢失后的数据安全变得更普遍。问题是平台和政府之间的争论会不断回到：谁能看到你和谁可以读取你。

Kevin Roose

但我们看到很多法案还是在限制加密，你怎么看这条线？

Cindy Cohn

在美国、英国、加拿大、澳大利亚都在上升。短期会反复出现。我的立场很简单：私密通信是民主社会的基础权利，不是技术偏好。

Casey Newton

你提过过去 EFF 常和大厂合作过版权、媒体内容分发，现在却更多与这些公司对立，原因是？

Cindy Cohn

以前它们更像用户赋权者。现在多数平台把‘隐私当生意模型’。当商业目标是长期监控，而不是赋能用户，我们就会天然分道扬镳。

Kevin Roose

这是不是价值观分歧，还是只是钱的问题？

Cindy Cohn

很难说清。企业当然在乎利润，但同样常见的，是它们陷入自己的回音室，忘了普通用户如何理解其行为后果。

Casey Newton

你提到过 Top 5 大科技公司控制了大量在线体验，这种集中如何影响隐私辩论？

Cindy Cohn

它们的决定会定义数字生活。我们不会自动站在某一家公司一边，而是站在用户和公民一边。比如企业支持某些监管豁免时，我们会反对。

Kevin Roose

关于大规模监听，很多人会觉得‘我的数据早已泄露’，没有意义。你怎么回应这种绝望？

Cindy Cohn

这正是‘隐私虚无主义’。数据有时效性，也会随时间降温。反应在于我们能否立法和产品层面及时把链条缩短：减少默认收集、减少可追踪性。

Casey Newton

FISA 702、签证、移民社媒监控在节目里你都被反复提到。你认为公众最该怎么理解风险？

Cindy Cohn

无论你是不是移民社群，你都可能在某个时刻被波及。风险会收缩圈层，今天看似遥远，明天就离自己更近。执法权要有边界，这就是法治。

Kevin Roose

你最近离开 X（现名为 X）是基于这些原因吗？

Cindy Cohn

是长期、系统性的考量。追权利和维护社区需要可持续投入，平台算法对言论空间的裁剪会让组织者越来越难发声。我们不排斥对话平台，但也要有离开的权利。

Casey Newton

你也提到自由言论本质是‘自由选择发声场所’，这和平台争议很冲突。

Cindy Cohn

没错。自由不是被迫一直在某个平台表达。真正的自由包含退出权，尤其当环境明显有害时。
